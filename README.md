# Скиллы из вебинара «Проснись, Нео» (23.09.2026)

Набор навыков (skills) для Claude Code, которыми из записи открытого вебинара «Проснись, Нео: что ИИ умеет в
сентябре 2026» собраны смонтированный двухчасовой ролик с анимациями, сторис из лучших моментов, PDF деки с
кликабельными роликами и сопроводительные материалы. Это не демо-версии: здесь рабочий код и заметки о граблях,
которые мы собрали на этом монтаже. Личные данные, ключи и имена участников из публичной копии убраны.

### video-editor: монтаж и конвейер эфира

Главный навык набора. Базовая часть: ffmpeg + Python для вырезки пауз, склейки, субтитров (караоке WhisperX → ASS),
переходов, цветокора, рефрейма 9:16, бит-синка и talking-head рилсов с AI-врезками. Новое после эфира — полный
конвейер **«запись эфира → длинный монтаж»**: выравнивание записей Zoom по диктофону, расшифровка Deepgram
с правками, разметка Gemini, чат в порядке прихода, опросы, четыре обработки слайдов, композиция Remotion `Program`
на весь кадр по EDL, рендер кусками несколькими воркерами, сведение звука, контроль и выдача (PDF саммари
и транскрипта, обложка, тексты для RuTube).
Когда звать: монтаж готового футажа любой длины, от рилса до двухчасового вебинара.
Фразы: «вырежи паузы», «склей видео», «наложи музыку», «смонтируй вебинар», «сделай монтаж эфира».
Начать чтение: `skills/video-editor/SKILL.md` → раздел «Запись эфира → длинный монтаж» →
`references/webinar-montage.md`. Около 70 граблей с номерами G-… (симптом → причина → лечение) — в
`references/webinar-gotchas.md`.

### sketch-course-video: скетч-анимация, уроки и сторис

Урок или сторис из записи спикера: рисунок проявляется по контурам исходной картинки (маска по штрихам, а не
шаблонная анимация), маркерные пометки, хромакей, субтитры с плашкой термина, вертикаль 9:16. Тот же движок
штрихов (`scripts/trace.py`) рисует живые скетчи слайдов в монтаже эфира. Новое — формат **story-v3**: пять сторис
1080×1920 из хайлайтов эфира (викторина, кейс, идея, событие, приглашение) с живым экраном в панели, кружком лица,
караоке, карандашными рисунками и финальной кнопкой (`templates/story-v3/`, `references/webinar-stories.md`).
Фразы: «видеоурок со скетчами», «скетч-ролик из вебинара», «сторис из эфира».

### video-shotcraft: промо-ролики на Remotion

Ролик о продукте с нуля: раскадровка, подбор кадров из 153 карточек-рецептов (открытия, типографика, появление UI,
камера, данные, переходы, финалы), звук и бит-синк, сборка Remotion-проекта по шаблону Ink Press. Пригодится для
заставок, промо и шоурилов. Фразы: «видео из лендинга», «промо-ролик продукта», «шоурил».

### manus-slides: презентации

Слайды полным циклом: 32 AI-стиля, HTML-шаблоны, темы в духе Manus, рисованный **exec-sketch** (светлый или
тёмный, заметки докладчика привязаны к слайду по ID, поэтому не съезжают при перестановке). Этим маршрутом
сделана дека вебинара. Новое — **PDF деки с кликабельными роликами** для раздачи после эфира: большая кнопка play
и подпись с длительностью на каждом ролике, ссылка на ролик в облаке, анонимная проверка каждой ссылки
(`scripts/pptx_video_rects.py`, `pdf_video_links.py`, `pdf_page_image.py`, `upload_videos_yadisk.py`).
Фразы: «презентация», «слайды», «скетчевая преза», «дека с видео в PDF».

### website-creation, landing-page-effects, design-taste: сайты

Этими навыками сделаны три 3D-лендинга, которые показывали на эфире. `website-creation` собирает сайт от чистого HTML
до React, `landing-page-effects` добавляет эффекты (3D-сцены, скролл-анимации, частицы), `design-taste` проверяет до и
после генерации, чтобы страница не выглядела шаблонной. Сами три сайта с кодом и промптом лежат в архиве по ссылке со
страницы эфира. Фразы: «сделай лендинг», «добавь 3D-эффект», «проверь дизайн на шаблонность».

### remotion-*: официальные навыки Remotion

`remotion-best-practices` (маршрутизатор ко всем остальным), `-create`, `-markup`, `-render`, `-studio`,
`-captions`, `-multimedia`, `-maps`, `-interactivity`, `-docs`, `-saas`, `-upgrade`. Это API-справочник для
правки Remotion-шаблонов из навыков выше. Скопированы без изменений в той версии, с которой делался монтаж
(skills 4.0.506). Самая свежая версия ставится командой `npx skills add remotion-dev/skills`.

## Как смонтирован эфир

Исходники: две локальные записи Zoom 4K (одна от со-ведущего), непрерывная запись диктофона (начало эфира есть
только на ней), чат Zoom с опросами и розыгрышем, дека из 76 рисованных слайдов с 15 роликами.
Итог: **2:03:20 = 184 998 кадров 25 fps**, 16 карточек глав, 1 935 реплик караоке, 403 пузыря чата, 11 опросов,
розыгрыш с баннерами и конфетти, громкость −16,0 LUFS / −1,5 dBTP. Правило, по которому делался монтаж: **«упрощение
не нужно»**. Если рендер идёт медленно, добавляют воркеры и готовят клипы на входе, но анимации не выбрасывают.

| Стадия | Что происходит |
|---|---|
| S0–S1 источники | прокси 1080p, WAV 16 кГц, чанки для «зрения» с таймкодом источника в кадре |
| S2 выравнивание | xcorr + GCC-PHAT по диктофону, кусочная карта сдвигов (у Zoom сдвиги ступенчатые, это не дрейф), проверка «на слух» независимыми расшифровками, часы чата, тембр, чистка кусков диктофона → `timeline.json` |
| S3 расшифровка | Deepgram nova-3 в два прохода, правки с доказательством, `tighten()` концов слов, сверка имён через faster-whisper |
| S4 зрение | Gemini по видео (смысл) + плотный проход кадров (время) + покадровые границы + отдельный проход по чувствительному (вкладки, почты, ники) |
| S5 чат | оба лога Zoom → единый порядок прихода, опросы, реакции, анонимизация |
| S6 стиль | `style.md` + `tokens.json`: одни числа для Remotion и сборщика EDL |
| S7 слайды | чистые PNG слайдов, разметка элементов Gemini, штрихи живого скетча, синхрон роликов деки |
| S8 обработки | четыре обработки слайда (ниже) |
| S9–S10 композиция и EDL | Remotion `Program` на весь кадр; сборщик EDL из модулей (часы, реплики, окна, события, планы, чат, опросы), внешний валидатор, нарезка на куски по 5 минут без шва |
| S11 рендер | ingest на GPU, лёгкий бандл с hardlink'ами клипов, 3 воркера, перерендер кусков после правок (провенанс), кодирование по ходу, склейка `concat -c copy` |
| S12 звук | одна цепочка голоса с точными паузами, музыка под интро/главами/аутро, двухпроходный loudnorm |
| S13 контроль | валидатор, кадры-пробы, тестовые вырезки, Gemini по кадрам, контактные листы, синхрон A/V против исходников |
| S14 выдача | таймкарта, PDF саммари и транскрипта, обложка, тексты RuTube, PDF деки, сторис |

**Четыре обработки слайда** (правило выбора — по тому, что говорит ведущий):

1. **(a) Чистый слайд с дрейфом.** Вместо мутной трансляции Zoom показывается чистый PNG с медленным дрейфом,
   направление чередуется, рядом лицо. Так идут демо и рассказ без опоры на слайд.
2. **(b) Живой скетч.** Когда ведущий перечисляет по пунктам, элементы слайда рисуются по контурам оригинала
   под его слова: удар каждого элемента приходится на слово-якорь, ручка паркуется и гаснет, в конце кроссфейд
   в чистый слайд.
3. **(c) Пометки внутри слайда.** На «вот здесь», цифре или выводе маркер обводит, подчёркивает или ставит
   галочку в координатах слайда. Пометки едут вместе с наездом камеры на деталь.
4. **(d) Дудлы вокруг слайда.** Для образа, метафоры или связи слайд уменьшается на «доску», а вокруг появляются
   стрелки, подписи и цифры. Подписи берутся только из сказанного или написанного.

Подробно, со всеми командами и замерами: `skills/video-editor/references/webinar-montage.md`.

## Установка

1. Скачайте репозиторий (`git clone https://github.com/JHamidun/prosnis-neo-skills` или Code → Download ZIP).
2. Скопируйте навыки в `~/.claude/skills/` (для одного проекта подойдёт и `<проект>/.claude/skills/`):

   ```bash
   mkdir -p ~/.claude/skills && cp -r prosnis-neo-skills/skills/* ~/.claude/skills/
   ```

   ```powershell
   New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
   Copy-Item -Recurse -Force .\prosnis-neo-skills\skills\* "$HOME\.claude\skills\"
   ```

   Если у вас уже стоит полный пак, одноимённые навыки заменятся версиями из этого набора. В них то же
   содержимое плюс материалы после эфира.
3. Перезапустите Claude Code. Навыки подхватятся по описаниям, так что достаточно сказать «смонтируй вебинар» или
   «сделай презентацию скетчами».
4. Remotion-шаблоны (`video-editor/templates/remotion-program`, `sketch-course-video/templates/story-v3`,
   `video-shotcraft/template`) копируются в папку задачи. Там выполняется `npm install`, а в папке навыка ничего
   не собирается.

Навыки ссылаются и на соседей из полного пака: `video-generation`, `video-montage`, `video-export`, `deepgram`,
`watch-video`, `image-generation`, `ace-step`, `submagic`. Без них эти ссылки просто не сработают, а всё, что лежит
в этом наборе, работает само по себе.

## Требования

| Что | Зачем |
|---|---|
| Python 3.11+ | все скрипты |
| Node.js 20+ (для `sketch-course-video` — 22+) | Remotion 4.0.526, React 19 |
| ffmpeg + ffprobe в PATH (libx264, libass) | монтаж, звук, субтитры |
| NVIDIA GPU с NVENC/NVDEC | **для большинства навыков по желанию, просто быстрее.** Но в конвейере эфира стадии `sources/proxies.py`, `sources/vision_chunks.py`, `render/ingest.py`, `render/encode_chunks.py`, `render/assemble.py` написаны под `h264_cuvid`/`h264_nvenc`. Без NVIDIA кодеки в них придётся заменить на `libx264`, и работать будет медленнее |
| PowerShell 7 (`pwsh`) | запуск воркеров рендера `render/start_workers.ps1` |
| Playwright + Chromium | PDF-материалы, обложка, HTML → PNG (`pip install playwright && playwright install chromium`) |

Python-пакеты:

```bash
pip install -r ~/.claude/skills/sketch-course-video/scripts/requirements.txt
pip install -r ~/.claude/skills/manus-slides/scripts/requirements.txt          # + requirements-generate.txt для генерации артов
pip install numpy scipy soundfile opencv-python Pillow PyMuPDF google-genai requests lxml qrcode playwright
pip install faster-whisper rembg      # по желанию: сверка имён в расшифровке, вырезка фигуры для обложки
```

Зависимости отдельных инструментов `video-editor` (WhisperX, librosa, auto-editor, scenedetect и т. д.) перечислены
в таблице его `SKILL.md`: ставьте только то, чем пользуетесь.

Эталонная машина, на которой снимались замеры в документации: ноутбук с Intel Core Ultra 9 185H (22 потока) и
RTX 4090 Laptop. Полный рендер двухчасового эфира на трёх воркерах идёт часами, поэтому на слабой машине
заложите больше времени. Качество от этого не страдает.

## Ключи API

В коде ключей нет. Скрипты берут их из переменных окружения, а конвейер эфира ещё и из файла, путь к которому указан в
`job.json` → `env_file` или в `$WEBINAR_ENV_FILE`. Нужны только те ключи, чьими стадиями вы пользуетесь:

| Переменная | Где взять | Для чего |
|---|---|---|
| `DEEPGRAM_API_KEY` | [console.deepgram.com](https://console.deepgram.com) | расшифровка nova-3 (эфир, talking-head, проверка выравнивания «на слух») |
| `GOOGLE_API_KEY` | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | Gemini: зрение, разметка слайдов и чата, контроль кадров, генерация артов. `GEMINI_API_KEY` скрипты снимают перед импортом SDK, потому что две переменные конфликтуют |
| `OPENAI_API_KEY` | [platform.openai.com/api-keys](https://platform.openai.com/api-keys) | по желанию: генерация слайдов `gpt-image-*` в `manus-slides` (exec-sketch) |
| `ELEVENLABS_API_KEY` | [elevenlabs.io](https://elevenlabs.io) (раздел API Keys в аккаунте) | по желанию: музыка и звуковые эффекты в шаблонах talking-head |
| `FREESOUND_API_KEY` | [freesound.org/apiv2/apply](https://freesound.org/apiv2/apply) | по желанию: `video-editor/scripts/sfx.py` |
| `YANDEX_OAUTH_TOKEN` | [oauth.yandex.ru](https://oauth.yandex.ru) (приложение с доступом к Яндекс.Диску) | по желанию: загрузка роликов деки для PDF с кликабельными видео |

Платные вызовы (Gemini, Deepgram, генерация картинок) делают только скрипты стадий. Движки рендера, EDL и штрихов
работают локально без сети.
