# Скиллы с эфира «Проснись, Нео» — монтаж видео и презентации

Открытый эфир Vibe Academy, 23 сентября 2026. На эфире показывали, как агент (Claude Code) монтирует ролики и собирает презентации. Здесь — сами навыки, которыми это делалось. Их можно поставить себе и повторить.

Автор: **Жемал Хамидун** · Vibe Academy. Полная конфигурация (400+ навыков): [claude-code-config-pack](https://github.com/JHamidun/claude-code-config-pack) · установщик в один клик: [hamidun.com/instal](https://hamidun.com/instal)

## Что внутри

### Монтаж видео
- **`video-editor`** — монтаж готового видео на FFmpeg + Python: вырезать паузы, склеить, субтитры (в том числе караоке), рефрейм в 9:16, переходы, цветокор, музыка и звуковые эффекты. Триггеры: «вырежи паузы», «сделай субтитры», «сделай вертикалку».
- **`sketch-course-video`** — урок или сторис из записи спикера со скетч-анимацией на Remotion: рисунок проявляется по контурам, маркер обводит главное, субтитры. Триггеры: «видеоурок со скетчами», «сторис из вебинара».
- **`video-shotcraft`** — промо-ролики продукта на Remotion: 150+ рецептов кадров. Триггеры: «видео из лендинга», «шоурил».
- **`remotion-*`** — официальные навыки Remotion (MIT, © Remotion, [remotion.dev](https://remotion.dev)): лучшие практики, субтитры, рендер, студия, анимации. Перенесены без изменений.

### Презентации
- **`manus-slides`** — слайды полным циклом: 32 стиля, HTML-шаблоны, рисованный скетч-стиль (светлый и тёмный) со спикер-заметками. Так собрана презентация эфира. Триггеры: «сделай презентацию», «скетчевая преза».

### Сайты (3D-лендинги из эфира)
- **`website-creation`**, **`landing-page-effects`**, **`design-taste`** — сайты от чистого HTML до React, 50+ эффектов для лендингов и проверка, чтобы лендинг не выглядел «типовым ИИ». Сами три сайта из эфира с кодом — в архиве по ссылке со страницы эфира.

## Как поставить

1. Установите [Claude Code](https://docs.anthropic.com/claude-code) (или установщиком: [hamidun.com/instal](https://hamidun.com/instal)).
2. Скопируйте папки из `skills/` в `~/.claude/skills/` (Windows: `C:\Users\<вы>\.claude\skills\`).
3. Перезапустите Claude Code и просто опишите задачу словами — навык подключится сам.

Для видео нужны **ffmpeg** и **Node.js 20+** (Remotion). Видеокарта NVIDIA ускоряет кодирование, но не обязательна.

Ключи API, если навыку нужен внешний сервис, указываются по имени переменной (например, `GOOGLE_API_KEY`, `DEEPGRAM_API_KEY`) — своих ключей в репозитории нет.

## Обновления

Навык монтажа длинной записи эфира (сведение частей Zoom и внешнего звука, транскрипт, разбор кадров, анимированный чат, скетч-анимации, рендер на видеокарте, проверка синхрона) будет добавлен в `video-editor` следующим обновлением этого репозитория.
