# Сторис из хайлайтов эфира (формат story-v3)

Маршрут, которым из двухчасового эфира 23.09.2026 сделаны 5 сторис 1080×1920 30 fps (19–46 с каждая, −16 LUFS):
живой экран эфира в панели с наездами и подсветкой шагов, кружок лица ведущего, караоке-субтитры, карандашные
рисунки, которые прорисовываются по контурам, выноски чата/цифр и финальная сцена с кнопкой. Шаблон проекта —
`templates/story-v3/` (Remotion `StoryV3`, инструменты, `STORYBOARD.md` — как собрать один клип). Исходные данные —
джоба монтажа эфира навыка `video-editor` (`references/webinar-montage.md`): `vision/scenes.json`, слова
`transcript/<part>.words.json`, 4K-записи.

## 1. Выбор пяти историй

По `scenes.json` (хайлайты, энергия, биты, опросы) и расшифровке — пять РАЗНЫХ видов, чтобы серия не повторялась:

| Вид | Что внутри | Пример эталона |
|---|---|---|
| викторина | вопрос залу + реальные ответы чата (анонимные пузыри, счётчик) + разгадка | «Правда или ИИ?» |
| кейс | задача → процесс на экране → результат, шаги подсвечены | агент, который ищет тендеры |
| идея | мысль ведущего, которой нет на экране, — рисунками (`result` отсутствует) | «песок = кремний» |
| событие | живой момент эфира: розыгрыш, реакция, цифра | барабан розыгрыша |
| приглашение | что дальше, кнопка (без цен продукта) | эфир в субботу |

Правило: история держится на одной фразе, которую зритель захочет проверить (`hook.title`), и на моменте, где это
видно на экране. Приватность — как в ролике: ни ников, ни фамилий, ни ленты участников Zoom, чат только анонимно.

## 2. EDL истории → медиа

`public/clips/<id>/edl.json` — куски источников (`src` = P1/P2, `in/out` в секундах источника), B-roll экрана из
других моментов, кропы, правки слов; непрерывные куски без фейда; лицо — по большинству слов. Затем:

```
python tools/prep_from_recording.py --job <джоба эфира>/job.json <id>
```

→ screen/result 2160×1262 (пропорция панели), face 440×440, voice −16 LUFS с фейдами 12 мс, words на часах истории,
media.json (длительности, вырезы, карта кусков история↔источник), контактные листы с сеткой 0,1. Кадры точные: каждый
кусок = `round(dur·30)`. Источники, полоса Zoom, квадраты лиц, спикеры — блок `stories` в job.json (docstring скрипта).
Проверено на эталоне: слова, длительности, вырезы и карта кусков всех 5 историй совпадают с сессией; s5 — 570 кадров
экрана = 19,0 с.

## 3. story.json

Все поля — `templates/story-v3/STORYBOARD.md` §2. Обобщения этой сессии: `result` необязателен (идея/приглашение),
`result.title`, `result.stamp`, `result.zooms`; `doneText`; `cuts` (кружок лица меняет кадрирование на каждом шве);
`process.faceLabels`; `callouts` четырёх видов — `chat` (анонимные пузыри, без имён), `tally` (столбики),
`stat` (досчёт чисел), `note` (рукописная заметка со стрелкой). Кадры: `frames = round((process + result + 7.5) · 30)`.
Удобно генерировать `story.json` маленьким скриптом клипа (`public/clips/<id>/_make_story.py`): координаты наездов и
целей шагов считаются от контактного листа, правка кропа — одним сдвигом для всех прямоугольников.

## 4. Рисунки

`tools/gen_art.py <art_spec.json>` (Nano Banana 2 по умолчанию; рядом с PNG — json с моделью, промптом и sha256) →
`tools/trace_art.py <png> paper|dark <traces.json>` (движок `scripts/trace.py` этого навыка: исходный растр не
меняется, по нему строятся штрихи). Стиль зафиксирован: ГРАФИТНЫЙ карандаш + штриховка + сдержанный коралл; navy — только
цвет текста (рисунки «тёмно-синими контурами» владелец отклонил, G-S11). Каждый PNG — глазами: без букв, ничего не
касается края, идея читается.

## 5. Рендер и доводка

```
python tools/render.py bundle                              # один раз; src общий для всех историй
python tools/render.py still <id> <кадр …>                 # пробы
python tools/render.py render <id> --concurrency 6 --out out/<id>_raw.mp4
python tools/fix_av.py out/<id>_raw.mp4 out/<id>.mp4       # обязательно
```

- Бандл отдаёт свою копию public: `render.py` перед каждым рендером синхронизирует папку клипа в бандл — новый клип не
  требует ребандла (G-R3 навыка video-editor). Ребандл — только при правке `src/`.
- Не больше двух рендеров одновременно (слоты), BELOW_NORMAL, повторы: на загруженной машине headless Chrome не успевает
  стартовать (G-R5). Рендер сторис рядом с полным рендером ролика замедляет оба (G-R6) — планировать.
- **Звук Remotion опаздывает на 42,7 мс**: AAC пишется с pts=0 без edit list / skip_samples, 2048 сэмплов праймера
  играются как звук. Замер на трёх окнах против 4K-источника: voice.wav 0 мс, mp4 Remotion −42,7 мс; лицо при этом на
  ~1 кадр раньше (25→30 fps) — суммарно ~70 мс, за пределом EBU R37. `fix_av.py` снимает 2048 ведущих сэмплов, добивает
  длину до видео, двухпроходный loudnorm −16 LUFS, видео копируется. После — xcorr против источника: 0 мс.
- Проверки готовой истории: кадры каждые 1,5 с глазами + Gemini (орфография субтитров и надписей, стиль рисунков,
  приватность), black/freeze/silence, A/V против источника, губы на смычках (закрыты в паузе, открыты на приступе).

## 6. Гочи сторис

| Симптом | Причина | Лечение |
|---|---|---|
| Подпись слайда обрезана справа («26 раз вокруг Зем…») | кроп демонстрации без полосы Zoom (x < 3504) отрезал и край слайда — подпись заходила под полосу | кусок пересобрать из 4K с кропом шире, область полосы залить из чистого арта деки (совмещение 0,0), все прямоугольники сдвинуть одним `DX` |
| Белая линия внизу кадра | рамка демонстрации Zoom на y ≈ 0,964 | базовый кроп `[0.037, 0, 0.96, 0.96]` на полнокадровых отрезках |
| Заголовок процесса и трекер мигают сквозь переход в финальную сцену | состояние «до CTA» снималось на первом кадре перехода | держать заголовок/трекер/кнопку/подпись лица до конца 8-кадрового перехода (`f < cta + 8`) |
| «Висячее» слово в отдельном куске субтитров | разбиение на куски не учитывало «…» | резать куски и после «…»; число прописью, которое рвёт кусок, — цифрой |
| Рисунок «не тот» | промпт арта | стиль в `gen_art.py` не менять (графит + коралл) |
| Звук отстаёт на ~70 мс | праймер AAC Remotion + лицо на кадр раньше | `fix_av.py` всегда |

Цельное проявление слайда по элементам (все надписи и рисунки слайда, а не одна иллюстрация) — навык `video-editor`,
`scripts/webinar/slides/sketch_slide.py` (тот же движок, `order_strokes(..., lettering=True)` для текстов).
