# Выдача эфира: тексты, PDF, обложка, дека, сторис, публикация

Справочник к `webinar-montage.md` (стадия S14). Всё текстовое считается от ИТОГОВОГО ролика: сначала EDL, потом
таймкарта, потом тексты. Правка EDL → `python scripts/webinar/deliver/rebuild_all.py --job j` пересобирает всё.

## 1. Таймкарта итогового ролика

`deliver/build_final_timemap.py --job j` → `materials/final_timemap.json`: куски `edl.json → pieces[]`
(src, t0, t1, from, to) в виде `{source, src_in, src_out, edit_in}`, без тизера (его фрагменты повторяют тело — их
слова стоят на своих местах), + главы `edl/chapters.json`. Кусок, чья длина в кадрах не равна длине в источнике
(> 0,08 с), останавливает сборку — это не вырез, а смена скорости. Одна таймкарта — один набор глав для транскрипта,
саммари и RuTube.

## 2. Транскрипт и саммари PDF

Шаблон `templates/pdf-materials/` (копия → `<job>/materials/pdf_templates/`, описание — `DATA_CONTRACT.md` там же):
HTML → A4 через Playwright/Chromium, дизайн ролика (navy-сцена, коралл, Manrope + Caveat + JetBrains Mono, вырезки
скетчей колоды с отделённым фоном). Эталон: транскрипт 44 страницы (200 абзацев, 16 глав), саммари 9 страниц.

- главы с таймкодами итогового ролика (якорь — карточка главы `card_n` или фраза), абзацы по спикеру / паузе
  ≥ 2,2 с / ~520 знаков, видеофрагменты — отдельными блоками;
- `data/transcript_redactions.json` — обязательные правки (приватность, правила владельца); сборка ПАДАЕТ, если
  правка не нашла места (фраза изменилась выше по цепочке — пересмотреть, а не пропустить);
- лёгкая литправка — паразиты только в запятых, повторы-заикания; эталон −4,3 % слов
  (`deliver/light_edit.py` — то же для любого текста);
- `--final` отказывается при плейсхолдерах `{UPPER_CASE}` и предварительных таймкодах; `--drop-pending-links` —
  отрендерить сейчас, спрятав ссылки, которых ещё нет;
- линтер правил текста: встроенные — e-mail/телефоны, суммы и цены, белый список ссылок; свои правила владельца
  (названия продукта, запрещённые утверждения, темы не для публичных текстов) — `job.json → materials.rules`,
  добавляются к встроенным (формат — `DATA_CONTRACT.md`);
- PNG-пруфы каждой страницы в `_qa/<kind>/` — смотреть глазами (обложка, оглавление, карточка главы, тело, CTA).

Шрифты PyMuPDF/PIL — статические веса, сигнатура файла (G-F1…G-F4).

## 3. Текст RuTube и прочие тексты

`deliver/make_text_materials.py --job j` → `materials/{transcript_clean.md, timecodes.txt, summary.md, rutube_meta.json}`:
абзац + «В ВЫПУСКЕ» + таймкоды (MM:SS до часа, H:MM:SS после; первый обязательно 00:00) + материалы + спикер;
описание ≤ ~4000 знаков, заголовок ≤ 100. Тексты пишутся руками в `materials/text_build/{summary,rutube_desc}.tpl.txt`
(`{TIMECODES}`, `{DURATION_HUMAN}` подставляются). Проверки: главы транскрипта == карточки ролика, EDL не менялся после
таймкарты, линтер правил, ссылки только из `materials.allowed_links`.

## 4. Обложка

Шаблон `templates/cover/` (копия → `<job>/materials/cover/`, тексты и ссылки — `cover.json` по образцу
`cover.example.json`):

1. `pick_frame.py` — кадр спикера в два раунда Gemini: кандидаты каждую секунду на отрезке, где спикер крупно
   (в Zoom-эфире часто единственный такой отрезок — ищется в `scenes.json`), топ-6 с причинами → ±0,5 с с шагом 0,1 с,
   2 самых резких кадра вокруг каждого (дисперсия Лапласиана на лице) → финал + запасной, оценки 1–10.
2. Кадр в полном разрешении (`ffmpeg -ss <t> -i <запись 4K> -frames:v 1`), `cutout.py` — вырез rembg
   `birefnet-portrait` + обеззараживание края под известный цвет фона + дожим альфы; остатки фона (спинка кресла
   в эталоне) — ручным полигоном, проверка на увеличенном крае.
3. `render_cover.py` — HTML → Playwright (DSF 2, Lanczos) → 1280×720 (RuTube: только QR Telegram, в стороне от
   плашки длительности) и 1200×675 + WebP q90 (сайт: оба QR); **QR декодируются обратно из готовой картинки** —
   в эталоне QR шаблона по умолчанию вёл на несуществующий профиль. После заливки на RuTube — перерендер с
   `--rutube-url` ролика.
4. `critique_pair.py` — Gemini попарно в ОБОИХ порядках (G-Q2) + поиск дефектов с жёсткими условиями заказчика;
   новая версия побеждает, только если побеждает в обоих порядках.

## 5. PDF деки с кликабельными роликами

Навык `manus-slides` («PDF деки с видео»): прямоугольники роликов — из `xfrm` pptx (`scripts/pptx_video_rects.py`,
G-P2), ролики — на файлообменник с публичными ссылками и md5-проверкой (`scripts/upload_videos_yadisk.py`), кнопки —
`scripts/pdf_video_links.py` (большая кнопка play + пилюля «Нажмите, чтобы посмотреть видео · m:ss», два ролика в
кадре — две нумерованные кнопки, G-P1; `--verify`: число ссылок, набор URI, страницы без видео побайтно те же),
страница-скриншот — `scripts/pdf_page_image.py`. Эталон: 45 ссылок на 13 страницах.

## 6. Сторис из хайлайтов

Навык `sketch-course-video` (`references/webinar-stories.md`, шаблон `templates/story-v3/`): 5 историй 1080×1920 по
`scenes.json` (викторина, кейс, идея, событие, приглашение) с карандашными рисунками, прорисовкой по контурам,
кружком лица, выносками чата/цифр и кнопкой; −16 LUFS.

## 7. Публикация (шаги без личных ID)

Личная инфраструктура владельца (аккаунты, каналы, ID постов, бот, рассылки) живёт в его навыках публикации; здесь
только шаги и грабли. Правило: сначала черновики, отправка/публикация — только после явного «ок» владельца, рассылки
не ночью.

- **RuTube**: файл с `+faststart` (без него заливка рвётся «Что-то сломалось», G-P4 — ремукс `-c copy`); видимость
  «по ссылке» — ролик доступен всем, у кого ссылка С КЛЮЧОМ `?p=` (`rutube.ru/video/private/<ID>/?p=…`, плеер
  `rutube.ru/play/embed/<ID>?p=…`; ключ — из `video_url` Studio API), без ключа — 404 у всех, кроме владельца (G-P3);
  обложка и описание с главами — из п. 3–4.
- **Пост на сайте (Tilda Feeds)**: черновик `active=''`; правка поста хелпером ставит `active='y'` — передавать
  текущее значение (G-P5); `mediatype` ставить явно (G-P5b); проверять анонимно (страница поста 404, getpost
  «Unavailable post» — черновик действительно скрыт).
- **PDF-материалы и ролики деки** на файлообменник — отдельными публичными ссылками, после заливки md5 и анонимная
  доступность каждой ссылки; ссылки подставить в PDF (`make_all.py --event-link … --pdf-link … --final`).
- **Анонимная проверка** всего опубликованного — без cookies, обычным HTTP-запросом (через `python`, не `curl | …`:
  такую связку режут охранники команд).
