## Приёмы, которых у нас не было

### Ken Burns на каждом стоп-кадре — без исключений

Неподвижная картинка в ролике читается как пауза, даже когда содержательно она
уместна: глаз ждёт движения и, не получая его, считает кадр ошибкой. Поэтому любой
стоп-кадр получает медленный наезд с уводом, а соседние кадры чередуют направление —
один наезжает, следующий отъезжает. Иначе весь ролик «дышит» в одну сторону и это
заметно.

```tsx
const scale = interpolate(frame, [0, durationInFrames], [1, 1.1], {easing: ease.inOut});
const pan   = interpolate(frame, [0, durationInFrames], [0, -25]);
// objectFit: cover + transform: scale(...) translateX(...)
```

Кадр можно посадить в скруглённую карточку: `borderRadius: 32`, `overflow: hidden`,
тонкая рамка `rgba(255,255,255,.08)` и глубокая мягкая тень снизу.

### Выход быстрее входа

Появление элемента — событие, к нему привлекают внимание. Уход — служебное действие,
и растянутый уход читается как заминка. Практическое правило: выход занимает примерно
половину времени входа. Это одна строка в коде и заметная разница в темпе.

## Типовые провалы, которых стоит избегать

**Эмодзи вместо иконок.** Эмодзи рисуется системным шрифтом в своих собственных
цветах и игнорирует палитру ролика. Зелёная звёздочка и синий глобус ломают правило
одного акцентного цвета молча, а совпадение цвета эмодзи с плашкой делает знак
невидимым. Рисовать глифы средствами CSS или SVG в цветах темы — либо проверять
каждый эмодзи на извлечённых кадрах.

**Отсутствие звуковых файлов — не повод отдавать немой ролик.** Минимальный набор
синтезируется скриптом в WAV: свист из всплеска шума, «поп» из падения высоты тона,
удар из синусоиды с затуханием, подложка из расстроенных синусоид. Ни одного
скачивания, результат одинаков при каждом прогоне.

**Проверка старого файла.** Забытый флаг перезаписи при повторном рендере оставляет
на диске прошлую сборку — и приёмка радостно подтверждает несуществующий результат.
Мы наступили на это независимо: `video-montage/scripts/review_cut.py` теперь первым
делом печатает возраст файла.

**Несовпадение длительности** композиции и содержимого сцены даёт мёртвый воздух в
конце.

**Шрифты.** Для крупного текста никогда не полагаться на системный по умолчанию —
подгружать выбранный явно.

## Чего у них строже, чем у нас

Отдельным обязательным шагом стоит **проверка результата** («никогда не пропускать»)
и правило **звук = половина воспринимаемого качества**. Второе мы вывели сами, собирая
ролик маскота: сборка прошла без ошибок, а последние семь секунд оказались немыми,
потому что микшер обрезал дорожку по длине первого входа.
